# Парсер музыкального магазина

## Задача
Получить подробную информацию о товарах и услугах с сайта `https://www.muztorg.ru/` для анализа продукции.

## Стек разработки

В этом проекте использованы следующие технологии и инструменты:

- **Java 17** – Современная версия Java, используемая для разработки сервера.
- **Spring Boot** – Фреймворк для создания веб-приложений на Java.
- **Spring Web** – Модуль для создания RESTful API.
- **Spring Data JPA** – Для работы с базой данных с помощью ORM.
- **Springdoc OpenAPI** – Генерация документации API в формате Swagger для удобства разработки и тестирования.
- **Redis** — для кэширования данных и улучшения производительности.

## API Endpoints

### 1. ```POST /api/v1/{category}```
**Описание**: Запуск процесса парсинга продуктов для указанной категории.

- **URL**: `/api/v1/{category}`
- **Метод**: `POST`
- **Параметры URL**:
    - `category` (обязательный) — категория продуктов для парсинга.
- **Параметры тела запроса** (`application/json`):
    - `start_price` (необязательный, по умолчанию: 1) — минимальная цена продукта.
    - `end_price` (необязательный, по умолчанию: 10,000,000) — максимальная цена продукта.
    - `new` (необязательный, по умолчанию: false) — фильтр для новых продуктов (true — только новые).

#### Пример запроса:
```POST /api/v1/elektrogitary```
```json
{
  "start_price": 100,
  "end_price": 10000,
  "new": true
}
```

#### Пример ответа:
```json
{
  "message": "Products successfully parsed",
  "success": true
}
```

### 2. ```GET /api/v1/product```
**Описание**: Получение списка продуктов с возможностью фильтрации по категориям, цене, рейтингу и продавцу.

- **URL**: `/api/v1/product`
- **Метод**: `GET`
- **Параметры запроса**:
    - `category` (необязательный) — категория продукта.
    - `start_price` (необязательный) — минимальная цена продукта (по умолчанию: 1).
    - `end_price` (необязательный) — максимальная цена продукта (по умолчанию: 10,000,000).
    - `min_rate` (необязательный) — минимальный рейтинг продукта (по умолчанию: null).
    - `seller` (необязательный) — имя продавца (по умолчанию: null).

#### Пример запроса:
```GET /api/v1/product?category=electronics&start_price=100&end_price=1000&min_rate=4.5&seller=BestSeller```

#### Пример ответа:
```json
[
  {
    "id": 1,
    "shopId": "12345",
    "name": "Product A",
    "seller": "BestSeller",
    "category": "electronics",
    "price": 500,
    "ratingValue": 4.8,
    "ratingCount": 120
  },
  {
    "id": 2,
    "shopId": "67890",
    "name": "Product B",
    "seller": "BestSeller",
    "category": "electronics",
    "price": 800,
    "ratingValue": 4.6,
    "ratingCount": 80
  }
]
```

### 3. ```GET /api/v1/category```
**Описание**: Получение списка всех категорий товаров.

- **URL**: `/api/v1/category`
- **Метод**: `GET`

#### Пример запроса:
```GET /api/v1/category```

#### Пример ответа:
```json
[
  {
    "name": "Обучение и курсы",
    "url": "muzykalnye-kursy"
  },
  {
    "name": "Укулеле и аксессуары",
    "url": "ukulele-i-akssesuary"
  },
  {
    "name": "Гитары",
    "url": "gitary"
  }
]
```

### 4. ```GET /api/v1/sub```
**Описание**: Получение списка подкатегорий товаров для заданной категории.

- **URL**: `/api/v1/sub`
- **Метод**: `GET`
- **Параметры запроса**:
    - `name` (обязательный) — название категории для получения подкатегорий.

#### Пример запроса:
```GET /api/v1/sub?name=gitary```

#### Пример ответа:
```json
[
  {
        "name": "Акустические гитары",
        "url": "akusticheskie-gitary",
        "count": 1000
    },
    {
        "name": "Электрогитары",
        "url": "elektrogitary",
        "count": 883
    },
    {
        "name": "Классические гитары",
        "url": "klassicheskie-gitary",
        "count": 345
    }
]
```
